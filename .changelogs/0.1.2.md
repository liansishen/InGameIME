## InGameIME 0.1.2

新增 BackpackEnhance 背包面板搜索框的 Rime 中文输入支持。

- 聚焦背包面板搜索框时优先选择该输入目标，提交文字后同步更新搜索与物品过滤结果。
- 候选窗跟随搜索框位置，移动面板或重建搜索框时保持当前输入目标稳定。
- 复用组合串清理逻辑，处理失焦、收起面板和关闭界面，并保留 lwjgl3ify 待处理文字缓冲。
- 新增 10 项回归测试；完整构建、60 项测试、Spotless 和 Checkstyle 均通过。

需要使用带背包面板搜索框的 BackpackEnhance 版本。实际 Minecraft 客户端交互仍需游戏内验收。

继续支持 Minecraft 1.7.10 / Forge 10.13.4.1614。发布 JAR 不包含 JNA、librime、输入方案或词典，请按 README 安装说明准备这些组件。
